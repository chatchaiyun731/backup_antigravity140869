ตั้งค่า Supabase Connection

กรุณากรอกข้อมูลการเชื่อมต่อจากหน้าการตั้งค่า API ใน Supabase Dashboard ข้อมูลจะถูกเก็บไว้ในเบราว์เซอร์ของคุณอย่างปลอดภัย

หมายเหตุ: ระบบจะใช้ RLS (Row Level Security) เพื่อควบคุมสิทธิ์การใช้งาน บัญชีผู้ใช้คนแรกที่สร้างจะได้รับสถานะผู้ดูแลระบบ (Admin)
