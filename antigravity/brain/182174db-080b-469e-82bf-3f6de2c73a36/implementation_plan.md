# แผนงานติดตั้งระบบประหยัดงบ (ปุ่มรีเฟรช และสวิตช์ควบคุมออโต้) 🚀

เราจะทำการเพิ่ม **"สวิตช์ เปิด/ปิด การรีเฟรชอัตโนมัติ"** และ **"ปุ่มกดดึงราคาสดทันที"** ไว้ในระบบ เพื่อให้คุณเปิดแช่จอหน้าพอร์ตได้ทั้งวันโดยแทบไม่เสียค่าบริการ API (เหลือเพียง ~0.50 บาทต่อวัน) และสามารถสั่งอัปเดตราคาสดได้ตามใจต้องการครับ

---

## 🛠️ รายละเอียดการเปลี่ยนแปลงที่เสนอ

### 1. ไฟล์ [financeApi.ts](file:///C:/Users/66830/.gemini/antigravity/scratch/investment-portfolio-tracker/src/services/financeApi.ts)
*   **เพิ่มสวิตช์ปิด/เปิด Auto-Refresh**: 
    - เพิ่มฟังก์ชัน `isAutoRefreshEnabled()` เพื่อตรวจสอบสถานะจาก LocalStorage (กำหนดให้ **ปิดการอัปเดตอัตโนมัติเป็นค่าเริ่มต้น** เพื่อประหยัดเงินที่สุด)
    - เพิ่มฟังก์ชัน `setAutoRefresh(enabled: boolean)` เพื่อเปิด/ปิดจังหวะเวลาดึงราคาและบันทึกค่าลงเครื่อง
*   **เพิ่มฟังก์ชันแมนนวลรีเฟรช**:
    - เพิ่มฟังก์ชัน `refreshPricesManually()` เพื่อดึงราคาตลาดจริงทันทีเมื่อผู้ใช้งานกดปุ่ม โดยฟังก์ชันนี้จะ **ข้ามระบบจำกัดเวลา 65 วินาที** เพื่อตอบสนองคำสั่งผู้ใช้ในทันที
*   **แก้ไขจังหวะเริ่มระบบตอนเปิดหน้าเว็บ**:
    - ตรวจวัดค่าสวิตช์ หากผู้ใช้ตั้งปิดออโต้ไว้ ระบบจะไม่ตั้งเวลา (setInterval) ดึงข้อมูลเบื้องหลัง

### 2. ไฟล์ [App.tsx](file:///C:/Users/66830/.gemini/antigravity/scratch/investment-portfolio-tracker/src/App.tsx)
*   **เพิ่มการแสดงผลบน Header (ขวาบนข้าง Badge เรียลไทม์)**:
    - **ปุ่มกด "รีเฟรชราคาสด" (Refresh Prices Manual)**: แสดงผลเป็นปุ่มไอคอนหมุนวนสวยงาม มีเอฟเฟกต์หมุนตอนกำลังดึงข้อมูล และปิดการกดซ้ำชั่วคราวขณะดึงราคาเพื่อความปลอดภัย
    - **สวิตช์ "อัปเดตอัตโนมัติ" (Auto-Refresh Toggle)**: แสดงเป็นสวิตช์ Toggle สวยงามแนวแก้วใส (Glassmorphism) สลับเปิด-ปิดได้สะดวก
*   **เพิ่ม State ควบคุม**:
    - `isAutoRefresh` และ `isRefreshing` เพื่อควบคุมสถานะการหมุนและหน้าตาปุ่มในเว็บจริง

### 3. แจ้งเตือนค่าบริการเพื่อความโปร่งใส (Cost Transparency Notices)
*   **ที่ปุ่มรีเฟรชราคา (Header)**:
    - เพิ่มข้อความกำกับขนาดเล็กสีส้มข้างใต้ปุ่มรีเฟรช: `(คิดค่าบริการ AI ค้นหาราคาสดครั้งละ ~0.50 บาท)` เพื่อเตือนสติผู้ใช้ทุกครั้งก่อนกดเรียกราคาสดจริง
*   **เมื่อกดปุ่มรีเฟรชราคา (Action Confirmation Toast)**:
    - แสดงข้อความป๊อปอัพแจ้งสถานะสั้นๆ ขณะกำลังดึงข้อมูล: `"กำลังดึงข้อมูลราคาสดและคำนวณผลลัพธ์ (คิดค่าบริการสืบค้นจริงประมาณ 0.50 บาท)"`
*   **ที่หน้าแชท (Real-time Chat)**:
    - เพิ่มคำอธิบายกำกับใต้กล่องเลือกตัวสวิตช์ Google Search Grounding ในไฟล์ `src/components/AiChat.tsx`: `*(เมื่อติ๊กถูก จะมีค่าบริการค้นหาข้อมูลสดในอินเทอร์เน็ตเพิ่มเติมประมาณ 0.50 บาทต่อการส่ง 1 ข้อความ)*`

## 🧪 แผนการตรวจสอบความถูกต้อง (Verification Plan)

### การทดสอบแมนนวล
1. **การโหลดครั้งแรก**: หน้าเว็บควรดึงราคาสดสำเร็จและคงราคานิ่งไว้โดยไม่รีเฟรชเพิ่ม (หากปิดสวิตช์ออโต้)
2. **ปุ่มรีเฟรชแมนนวล**: เมื่อกดปุ่มราคาในพอร์ตควรหมุนอัปเดตราคาสดทันที
3. **การบันทึกค่า**: เมื่อกดปิดสวิตช์ออโต้แล้วรีเฟรชหน้าเว็บ ค่าต้องยังคงบันทึกปิดไว้อยู่เหมือนเดิม
4. **ความคุ้มค่า**: ยอดการเรียกใช้งานจะนิ่งสนิทหากเปิดจอทิ้งไว้ ไม่มีการส่งคำขอเกินจำเป็น
