# 📄 ประวัติบทสนทนาและการพัฒนา: ระบบตรวจสอบพัสดุประจำปี (AssetFlow)

ยินดีต้อนรับสู่เอกสารบันทึกประวัติการสนทนาของระบบ **AssetFlow (ระบบเดินตรวจ / ตรวจสอบพัสดุประจำปี)** ซึ่งได้รับการพัฒนาขึ้นตามความต้องการของคุณในการตรวจสอบพัสดุด้วย QR Code และระบบวิเคราะห์เอกสาร PDF บน Cloudflare Pages และ Supabase

---

## 📋 สรุปฟังก์ชันและรายละเอียดของระบบ (System Overview)

* **ชื่อระบบ**: **AssetFlow** (ระบบบริหารจัดการและติดตามครุภัณฑ์ประจำปี)
* **รูปแบบการติดตั้ง (Deployment)**: 
  - **Frontend**: หน้าเว็บหน้าเดียว (Single Page Application - SPA) โฮสต์อยู่บน **Cloudflare Pages** (HTTPS)
  - **Backend**: เชื่อมต่อ API โดยตรงกับระบบ **Supabase** (Database, Auth และ Storage)
* **สิทธิ์การใช้งาน (User Roles)**:
  - **Admin (ผู้ดูแลระบบ)**: มีสิทธิ์จัดการพัสดุ นำเข้าข้อมูล PDF เปลี่ยนสิทธิ์ผู้ใช้ และพิมพ์ QR Code
  - **Officer (เจ้าหน้าที่พัสดุ)**: มีสิทธิ์เพิ่ม แก้ไขข้อมูล จัดการข้อมูลพัสดุ และพิมพ์ QR Code
  - **Auditor (ผู้ตรวจสอบ)**: มีสิทธิ์สแกนตรวจสอบพัสดุผ่านหน้างาน ถ่ายรูปพัสดุ และส่งผลการประเมิน
* **ฟังก์ชันเด่น**:
  - **Smart PDF Importer**: นำเข้าข้อมูลจากไฟล์บัญชีพัสดุ PDF วิเคราะห์ดึงเลขครุภัณฑ์อัตโนมัติ (เช่น รูปแบบ `1800-007-0019/0014`)
  - **Bulk QR Generation**: แปลงข้อมูลพัสดุเป็น QR Code และสามารถสั่งพิมพ์สติกเกอร์หลายรายการพร้อมกัน
  - **Camera Scanner**: เปิดกล้องมือถือสแกนคิวอาร์โค้ดพัสดุเพื่อเข้าแบบฟอร์มตรวจสอบสถานะได้ทันที
  - **Excel/CSV Export & Report**: ดาวน์โหลดสถิติความคืบหน้าออกมาเป็นไฟล์ Excel (ภาษาไทยสมบูรณ์) หรือสั่งพิมพ์รายงานสรุปความคืบหน้า
