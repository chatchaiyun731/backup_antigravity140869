# แผนการแยกตารางฐานข้อมูลของระบบ G-Patrol ออกจากระบบพัสดุเดิม

เพื่อป้องกันไม่ให้ข้อมูลจุดตรวจในโครงการ G-Patrol และข้อมูลพัสดุในระบบเดิมปะปนกันในฐานข้อมูล Supabase เดียวกัน เราจะทำการแยกตารางของทั้งสองระบบออกจากกันอย่างเด็ดขาด โดยการตั้งชื่อตารางใหม่สำหรับ G-Patrol โดยเฉพาะ

---

## 🏗️ การแยกโครงสร้างตารางใหม่ (New Schema separation)

| ระบบตรวจสอบพัสดุเดิม (ยังคงเก็บไว้) | ระบบจัดการเดินตรวจ (G-Patrol ใหม่) | หน้าที่การจัดเก็บ |
| :--- | :--- | :--- |
| `profiles` | **`g_patrol_users`** | บัญชีผู้ใช้งานระบบเดินตรวจ |
| `assets` | **`g_patrol_assets`** | รายการจุดตรวจ (Checkpoints) |
| `audit_records` | **`g_patrol_audit_records`** | ประวัติการสแกนเช็คอินจุดตรวจ |

---
