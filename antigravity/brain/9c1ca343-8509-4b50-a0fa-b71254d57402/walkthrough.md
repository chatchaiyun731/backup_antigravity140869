# คู่มือแนะนำและการยืนยันผลการพัฒนาระบบ: AssetFlow (รุ่นคำนวณค่าเสื่อมราคาและประวัติบัญชี)

ระบบ **AssetFlow (ระบบบริหารจัดการและติดตามครุภัณฑ์ประจำปี)** ได้รับการปรับปรุงโครงสร้างเพื่อรองรับการนำเข้าไฟล์เอกสารแบบยืดหยุ่น 100%:
1. **แยก Schema ฐานข้อมูลเด็ดขาด**: แยกตารางข้อมูลไปสร้างใน Schema `asset_audit` เพื่อไม่ให้ทับซ้อนกับระบบอื่น
2. **เปลี่ยนระบบล็อกอินเป็น Username / Password**: สมัครและเข้าใช้งานได้ทันที ไม่ต้องมีขั้นตอนตรวจสอบอีเมลให้ยุ่งยาก
3. **ระบบสแกนเอกสาร PDF แบบคู่ขนาน (Smart Multi-Mode PDF Parser)**:
   - **โหมดดิจิทัล (Digital Mode)**: ดึงข้อมูลตัวอักษรดิจิทัลทันทีใน 1 วินาที เหมาะกับไฟล์ส่งออกจากระบบตรง
   - **โหมดสแกนรูปภาพและหมุนองศาอัตโนมัติ (Auto-Rotation OCR Mode)**: หมุนหาทิศทางตัวหนังสือแนวราบและสแกนเร็วด้วยรูปภาพหยาบก่อน (Fast Pre-check) จากนั้นรันละเอียดรอบเดียว ช่วยประหยัดเวลากว่าเดิม 10 เท่า!
4. **ระบบดึงและจัดเก็บประวัติความเคลื่อนไหวและค่าเสื่อมราคา (Asset Depreciation & Transaction History)**:
   - บันทึกประวัติบัญชีความเคลื่อนไหวครุภัณฑ์แต่ละตัวลงตารางประวัติย่อย (`asset_transactions`) โดยสกัดข้อมูลวันเดือนปี รายการ จำนวน ราคาต่อหน่วย ค่าเสื่อมปีนี้ ค่าเสื่อมสะสม และมูลค่าสุทธิ จากตารางในกระดาษโดยตรงโดยไม่มีข้อยกเว้น!
   - แสดงตารางประวัติค่าเสื่อมราคาทั้งหมดให้ผู้ตรวจ (Auditor) ตรวจเช็คได้สดๆ ทันทีจากหน้าจอตรวจนับครุภัณฑ์บนมือถือหรือคอมพิวเตอร์!

## 🛠️ ขั้นตอนการติดตั้งและย้ายฐานข้อมูล (Database Setup Guide)

เพื่อให้ระบบพร้อมทำงาน ให้ดำเนินขั้นตอนตั้งค่า 3 ส่วนหลักดังนี้ครับ:

### 1. การรัน SQL สร้างตารางข้อมูลใน Schema `asset_audit`
1. เปิดหน้าโครงการของคุณใน **Supabase Console**
2. ไปที่เมนู **SQL Editor** ทางด้านซ้าย > คลิก **New query** (สร้างคิวรีใหม่)
3. คัดลอกเนื้อหาทั้งหมดในไฟล์สคริปต์ [db-setup.sql](file:///C:/Users/66830/.gemini/antigravity/scratch/asset_audit_system/db-setup.sql) ไปวางในช่องกรอกโค้ด
4. คลิกปุ่ม **Run** เพื่อดำเนินการสร้างห้องเก็บข้อมูล ตาราง และทริกเกอร์
   * *หมายเหตุ: บัญชีผู้ใช้งานที่สมัครสมาชิกเป็น Username แรกสุดในตารางจะได้รับบทบาทเป็นผู้ดูแลระบบ (Admin) โดยอัตโนมัติ*

### 2. การเปิดสิทธิ์การเข้าถึง Schema บนหน้าเว็บบอร์ด (Exposed schemas)
1. ในหน้าโครงการ Supabase คลิกปุ่มฟันเฟือง **`⚙️ (Project Settings)`** ที่เมนูด้านซ้ายล่างสุด
2. คลิกเลือกหัวข้อเมนู **`Data API`** (หรือ `API`)
3. มองหาช่องกรอกที่ชื่อ **`Exposed schemas`**
4. คลิกเปิดรายการตัวเลือกและติ๊กเครื่องหมายถูกที่ **`asset_audit`** (และของ G-Patrol ที่ชื่อ **`g_patrol`** หากต้องการใช้งานควบคู่กัน)
5. หากมีปุ่มสีเขียว **`Save changes`** ขึ้นมา ให้กดบันทึกเพื่อยอมรับสิทธิ์

## 📱 การตรวจสอบผลประวัติบัญชีและค่าเสื่อมราคาพัสดุ (Asset History View)

เมื่อมีการสแกนและนำเข้าไฟล์ PDF ทะเบียนคุมทรัพย์สินที่มีรายการตารางคำนวณด้านล่าง:

1. **สกัดข้อความอัตโนมัติ**: ตัวถอดรหัส OCR จะทำการแกะรายการความเคลื่อนไหวจากตารางในเอกสารตามปีปฏิทิน (เช่น `30 ก.ย. 66`) รวมถึงสถิติคำนวณค่าเสื่อมสะสม และมูลค่าสุทธิ `1.00 บาท`
2. **บันทึกลงฐานข้อมูล**: เมื่อกดนำเข้า ระบบจะบันทึกข้อมูลพัสดุพร้อมพ่วงตารางบัญชีค่าเสื่อมราคาเข้าด้วยกัน
3. **การเข้าตรวจสอบในฐานะผู้ตรวจ (Auditor)**:
   - เมื่อสแกน QR Code หรือกรอกเลขค้นหาพัสดุเพื่อเข้าเมนูตรวจสอบ (Audit Form)
   - หน้าจอจะปรากฏกล่องตาราง **"ประวัติการคำนวณและค่าเสื่อมราคา"** ดึงรายการจากฐานข้อมูลมาโชว์ให้เห็นอย่างชัดเจนในแนวราบ (แสดงวันเดือนปี รายการ ค่าเสื่อมปีนี้ ค่าเสื่อมสะสม และมูลค่าคงเหลือ) ช่วยให้เจ้าหน้าที่และผู้ตรวจสอบประเมินมูลค่าพัสดุและอายุการใช้งานประกอบการตรวจนับได้อย่างสมบูรณ์แบบครับ!
