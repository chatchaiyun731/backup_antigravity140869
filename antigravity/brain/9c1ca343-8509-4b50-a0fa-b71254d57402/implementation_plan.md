# แผนการปรับปรุงระบบ: เพิ่มระบบสแกนเอกสารภาพถ่ายด้วย OCR (AssetFlow)

ปรับปรุงหน้าต่างนำเข้า PDF ให้มีความยืดหยุ่นสูงสุด โดยสามารถอ่านได้ทั้ง **ไฟล์ PDF ดิจิทัลต้นฉบับ** (อ่านทันทีใน 1 วินาที) และ **ไฟล์ PDF ที่เกิดจากการสแกนภาพถ่าย/เอกสารสีกระดาษ** (ผ่านระบบ OCR ภาษาไทย-อังกฤษ) โดยติดตั้งไลบรารี **Tesseract.js** เพื่อประมวลผลบนเบราว์เซอร์ของผู้ใช้โดยตรง

### 2. [MODIFY] [pdf-parser.js](file:///C:/Users/66830/.gemini/antigravity/scratch/asset_audit_system/pdf-parser.js)
- เพิ่มขั้นตอนการตรวจสอบสิทธิ์ข้อความในแต่ละหน้ากระดาษ:
  - **ขั้นที่ 1 (Digital Mode)**: ลองดึงข้อความจากไฟล์ดิจิทัลก่อน หากมีข้อความและพบเลขครุภัณฑ์ จะนำเข้าทันทีเพื่อความเร็วสูง
  - **ขั้นที่ 2 (OCR Mode Fallback)**: หากดึงข้อความแล้วพบว่าหน้ากระดาษว่างเปล่า (ไม่มีตัวหนังสือดิจิทัล) หรือไม่พบเลขครุภัณฑ์ ระบบจะเปลี่ยนไปเปิดการทำงานของ **OCR** อัตโนมัติ:
    - เรนเดอร์หน้า PDF หน้านั้นออกมาเป็นรูปภาพบน `<canvas>` ชั่วคราว (กำหนดขนาด Scale: 2.0 เพื่อให้ภาพคมชัดสูงสำหรับการทำ OCR)
    - เรียกใช้คำสั่ง `Tesseract.recognize(canvas, 'tha+eng')` เพื่อถอดรหัสข้อความภาษาไทยและภาษาอังกฤษจากรูปภาพ
    - ส่งข้อความที่ได้จาก OCR เข้าวิเคราะห์ในตัวจับตารางคุมทรัพย์สิน (parseCardStyle) หรือสแกนแถวข้อความ (parseLine)
- แสดงความคืบหน้า (Progress) การทำ OCR ในแต่ละหน้า เช่น `กำลังทำ OCR หน้า 1/2: กำลังประมวลผลภาษา...` เพื่อให้ผู้ใช้งานทราบความคืบหน้า
